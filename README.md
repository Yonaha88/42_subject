# 42 Subject Portfolio

42の課題を進捗のマイルストーンごとに整理したリポジトリ。

## 構成

```
.
├── milestone00/
│   └── libft            C標準ライブラリの再実装
├── milestone01/
│   ├── ft_printf         printf() の再実装
│   ├── get_next_line     ファイルディスクリプタから1行ずつ読み込む関数
│   └── push_swap         スタックを使ったソートアルゴリズム（ペア課題）
└── milestone02/
    ├── python_module/    Pythonピスキン課題（module00〜module10）
    └── a_maze_ing        迷路生成・探索プログラム（ペア課題）
```

## Milestone 00

| 課題 | 概要 |
| --- | --- |
| [libft](milestone00/libft) | 文字列・メモリ操作・文字判定・出力・単方向リストなど43関数からなる自作Cライブラリ |

## Milestone 01

| 課題 | 概要 |
| --- | --- |
| [ft_printf](milestone01/ft_printf) | `printf()` の主要な変換指定子（%c, %s, %p, %d, %i, %u, %x, %X, %%）を再実装 |
| [get_next_line](milestone01/get_next_line) | ファイルディスクリプタから1行ずつ読み込んで返す関数。静的変数の扱いを学ぶ課題 |
| [push_swap](milestone01/push_swap) | 2つのスタックのみを使い最小の操作回数で数値を並び替えるアルゴリズム課題（ペア課題） |

## Milestone 02

| 課題 | 概要 |
| --- | --- |
| [python_module](milestone02/python_module) | Pythonピシンの各モジュール（module00〜module10） |
| [a_maze_ing](milestone02/a_maze_ing) | 設定ファイルから迷路を生成し、BFSで解を求めて端末に描画するプログラム（ペア課題） |
